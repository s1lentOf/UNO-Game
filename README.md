# ♥️♦️ UNO-Game
The 2-Player UNO card game is a program that I personally developed using Java. It is designed to provide an enjoyable and engaging experience for two players, replicating the classic UNO gameplay in a digital format. 

>[!NOTE] 
>This game can only be played in a console and the amount of players is fixed (2 players only).

## Brief Description 
This project is a digital implementation of the classic card game **UNO**. The game allows players to experience **UNO** through an interactive console. It features essential gameplay mechanics, including card matching by color or number, action cards like Skip, Reverse, Draw Two, and Wild cards, and proper turn-based logic.

## Features

- 📝 User-friendly console interface.
- ✅ 2-players can play one versus another.
- 🎯 Difficulty Modes: Easy and Hard.
- 🃏 Special Cards: Draw Two, Wild, Wild Draw Four, Skip, and Reverse included!
- ⚠️ Penalty System: Forgetting "UNO" means extra cards!

## Game manual

- ***Step 1*** : At the beginning of the game, type ‘n’ to start the game, or type ‘q’ to quit the game.

- ***Step 2*** : Then, enter the name for the first player and the name for the second player. Each name cannot be blank.

- ***Step 3*** : Choose the difficulty of the game. The game difficulty can either be ‘easy’ or ‘hard’. If you choose the game to be ‘easy’, the system will remind you to type ‘UNO’ every time you are left with 1 card.

- ***Step 4*** : Each player has their turn to place a card, starting from the first player. To place a card type ‘1’ and then type the number of the card you want to place (unique number is printed under each card) or, if you do not have a card to place, type ‘2’ to get a top card from the draw pile. Then, if you got a good card and you can place it, you can type ‘1’ and place that card. Otherwise, type ‘p’ to pass and the turn will go to the opponent.
